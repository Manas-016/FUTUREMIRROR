FUTUREMIRROR 🔮
FUTUREMIRROR is an AI-powered web application that analyzes user input and generates a prediction or representation of their future self based on decision patterns.
This project is built using a modern full-stack architecture with a React frontend and a Node.js + Express backend.
🚀 Features
AI-based future prediction system
Interactive and responsive user interface
Full-stack architecture (Frontend + Backend)
Clean and modular project structure
Real-time API communication
